# Пепел Цивилизации

Постапокалиптический рогалик на Python/JavaScript с возможностью запуска в браузере.

## Сеттинг

2077 год. Прошло 50 лет после Великой Войны - глобального ядерного конфликта, уничтожившего развитую технологическую цивилизацию уровня 2025 года. Радиация изменила мир - у некоторых выживших пробудились магические способности. Сильный пиромант кратковременно по мощи равен крематорию, способен испепелять целые группы врагов.

## Запуск

### Вариант 1: Standalone версия (рекомендуется)

Просто откройте `game_standalone.html` в браузере. Работает полностью автономно без сервера.

### Вариант 2: PyScript версия

1. Запустите локальный сервер:
```bash
python -m http.server 8000
```

2. Откройте в браузере: http://localhost:8000/index.html

## Управление

- **WASD / Стрелки** - движение (включая диагонали: Q, E, Z, X)
- **SPACE** - пропустить ход
- **1-5** - использовать заклинание
- **G** - подобрать предмет
- **>** - спуститься по лестнице
- **ESC** - отмена выбора цели

## Классы персонажей

### Пиромант
Повелитель огня. Способен испепелять врагов потоками пламени невероятной мощности.
- Высокий интеллект и мана
- Сопротивление огню 50%
- Заклинания: Огненный шар, Поток пламени, Огненная стена, Испепеление, Взрыв сверхновой

### Сталкер
Выживальщик пустошей. Мастер скрытности и дальнего боя.
- Высокая ловкость и выносливость
- Сопротивление радиации 30%
- Заклинания: Меткий выстрел, Уклонение

### Технопріст
Жрец машинного культа. Повелевает электричеством и техникой.
- Высокий интеллект
- Сбалансированные сопротивления
- Заклинания: Электрошок, Взлом дрона, EMP-импульс

### Пси-оперативник
Псионик. Атакует и защищается силой разума.
- Максимальный интеллект и мана
- Заклинания: Ментальный удар, Контроль разума, Пси-щит

### Мутант
Мутировавший от радиации. Невероятно живуч.
- Максимальное HP и сила
- Сопротивление радиации 80%
- Заклинания: Регенерация, Кислотный плевок, Радиоактивный взрыв

## Враги

- **Рейдеры** - вооружённые мародёры
- **Псы-мутанты** - быстрые и опасные
- **Гули** - бывшие люди, изменённые радиацией
- **Роботы-охранники** - остатки довоенных систем безопасности
- **Дикие пироманты** - сошедшие с ума маги огня (с 3 этажа)
- **Когти смерти** - смертельно опасные мутанты (с 5 этажа)

## Механики

- Пошаговый геймплей
- Процедурная генерация уровней
- Система поля зрения (FOV)
- 5 уникальных классов с разными заклинаниями
- Предметы: оружие, броня, расходники
- Радиоактивные зоны наносят урон
- Система уровней и прокачки
- Сопротивления к типам урона

## Технологии

- Python 3.10+ (игровой движок)
- PyScript (для браузерной версии)
- Vanilla JavaScript (standalone версия)
- HTML5/CSS3
